## Sobre o projeto

O site reúne minha apresentação profissional, habilidades, projetos, certificados e trajetória na tecnologia, além de canais para contato.

Sua identidade visual combina fundo escuro, tons metálicos e detalhes em azul, com animações sutis e uma interface adaptada a computadores, tablets e celulares.

## Tecnologias utilizadas

- React
- TypeScript
- TanStack Start e TanStack Router
- Vite
- Tailwind CSS
- shadcn/ui
- Lucide Icons

Desenvolvido com o apoio do Lovable.

## Funcionalidades

- Apresentação pessoal com foto e painel de código.
- Navegação fixa com destaque da seção ativa e menu para celular.
- Seção de tecnologias e habilidades.
- Barras de nível de conhecimento, incluindo React avançado.
- Seleção de projetos reais com links para demonstrações e repositórios.
- Galeria de certificados com visualização ampliada.
- Formação acadêmica e linha do tempo da minha jornada.
- Links para GitHub, LinkedIn, WhatsApp e e-mail.
- Formulário que abre o aplicativo de e-mail com a mensagem preenchida.
- Animações com suporte à preferência por movimento reduzido.

## Organização do projeto

- `src/components/portfolio/`: componentes das seções do portfólio.
- `src/lib/portfolio-data.ts`: dados pessoais, habilidades, certificados e trajetória.
- `src/lib/portfolio-projects.ts`: informações dos projetos apresentados.
- `src/routes/`: páginas e estrutura de navegação.
- `src/assets/`: fotos e imagens utilizadas.
- `src/styles.css`: tema visual, estilos e animações.
