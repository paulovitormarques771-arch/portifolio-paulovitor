# Code Horizon

Crie uma **landing page profissional, moderna e tecnológica para meu portfólio pessoal como desenvolvedor de software**, com aparência premium e foco em desenvolvimento web.

## ESTILO VISUAL

Quero um design extremamente moderno, elegante e profissional, inspirado em sites de desenvolvedores, startups de tecnologia e empresas de software.

Paleta principal:

* Fundo predominante: preto/cinza muito escuro
* Cinza grafite
* Cinza metálico
* Azul metálico
* Azul elétrico apenas para pequenos destaques
* Branco/cinza claro para textos

Evite cores muito vibrantes ou aparência infantil.

Utilize:

* Gradientes discretos em azul metálico* Efeitos de iluminação/glow azul
* Glassmorphism de forma moderada
* Bordas finas e modernas
* Sombras suaves
* Cards com efeito de profundidade
* Pequenas partículas ou elementos tecnológicos no background
* Linhas e detalhes geométricos discretos

O visual deve transmitir:
**tecnologia + programação + inovação + profissionalismo + sofisticação.**

O fundo deve ser escuro, com elementos tecnológicos sutis se movimentando lentamente.
